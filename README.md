# 1v1RtpQueue
A Minecraft 1.21.11 plugin that provides a command-based 1v1 queue system with fully customizable requirements, messages, and configuration options.


# Features

- Command-based 1v1 queue system
- Customizable requirements
- Customizable messages
- Flexible configuration options
- Designed for PvP and CPvP Minecraft servers
- Built for Minecraft 1.21.11
